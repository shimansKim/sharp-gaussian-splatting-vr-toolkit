Splatia PC Server {version}
======================

Quest의 Splatia 앱에서 PC에 있는 파일(PLY·영상·사진)을 보게 해 주는 프로그램입니다.
파일은 같은 공유기(같은 Wi-Fi)의 Quest에만 읽기 전용으로 보여 줍니다. 인터넷으로 보내지 않습니다.
작업 표시줄 오른쪽 아래(트레이)에 아이콘으로 떠 있고, 관리 창에서 공유 폴더와 옵션을 바꿉니다.

[설치 방법 1: 설치 파일 (권장)]
1. Splatia-PC-Server-{version}-Setup.exe 를 두 번 누르고 안내에 따라 [다음]을 누릅니다.
   관리자 권한은 필요 없습니다. 내 계정에만 설치됩니다.
2. 원하면 "바탕화면 바로가기"와 "Windows를 시작할 때 자동으로 실행"에 체크합니다.
3. 설치가 끝나면 [Splatia PC Server 실행]을 누릅니다. 시작 메뉴에서도 실행할 수 있습니다.

[설치 방법 2: zip]
1. zip을 풀고 폴더를 원하는 곳(예: 문서)에 그대로 둡니다. exe 파일만 따로 옮기지 마세요.
2. "Splatia PC Server.exe"를 두 번 누릅니다. 시작 메뉴 바로가기는 만들어지지 않습니다.

[처음 실행할 때]
- "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
- Windows 방화벽 창이 뜨면 "개인 네트워크"에 체크하고 [액세스 허용]을 누릅니다.
- 처음에는 "문서\SHARP VR" 폴더가 공유됩니다. 볼 파일을 여기에 넣으세요.
- Quest의 Splatia 앱 목록에서 [PC] 항목을 엽니다. 처음 한 번은 30초쯤 걸릴 수 있습니다.

[관리 창]
- 트레이 아이콘을 두 번 누르거나, 오른쪽 버튼 → [관리 창 열기]를 누릅니다.
- 공유 폴더를 추가하거나 뺍니다. 고른 폴더는 다음 실행에도 기억됩니다.
- 포트, Windows 시작 시 자동 실행 같은 옵션을 바꿉니다.
- 관리 창을 닫아도 앱은 트레이에서 계속 실행됩니다.
- 끝내려면 트레이 아이콘을 오른쪽 버튼으로 눌러 [종료]를 선택합니다. 종료하면 연결이 끊깁니다.

[업그레이드와 제거]
- 새 설치 파일을 그대로 실행하면 덮어 설치됩니다. 실행 중인 앱은 알아서 종료됩니다. 설정은 유지됩니다.
- 제거: Windows 설정 > 앱 > 설치된 앱에서 "Splatia PC Server"를 제거합니다.
  제거할 때 저장된 설정을 지울지 묻습니다. [아니요]를 누르면 설정을 보관합니다.
- zip으로 쓴 경우: 앱을 종료한 뒤 폴더를 지웁니다.

[연결이 안 되면]
- Quest와 PC가 같은 공유기에 연결되어 있는지 확인하세요.
- Windows 설정 > 네트워크 및 인터넷 > 현재 연결의 "네트워크 프로필 유형"이 "개인"인지 확인하세요.
- 방화벽에서 막았다면: Windows 보안 > 방화벽 및 네트워크 보호 > 방화벽에서 앱 허용
  > "Splatia PC Server"의 "개인"에 체크합니다.
- 관리 창에 나온 "PC 주소"(예: http://192.168.0.23:8787)를 앱의 PC 카드 > [연결 설정]에 적습니다.

[알아 두세요]
- 공유 폴더는 같은 네트워크의 기기에 읽기 전용으로 보입니다. 집처럼 믿을 수 있는 네트워크에서만 실행하세요.
- 설정(설정 파일과 공유 폴더 목록)은 %LOCALAPPDATA%\SHARP PC Server 에 저장됩니다. 설치 폴더와는 다른 곳입니다.
- 포함된 오픈소스 라이선스는 licenses 폴더에 있습니다.
