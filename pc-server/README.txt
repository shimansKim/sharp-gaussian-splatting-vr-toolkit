SHARP PC 서버 {version}
======================

Quest의 SHARP 뷰어 앱에서 PC에 있는 파일(PLY·영상·사진)을 보게 해 주는 프로그램입니다.
파일은 같은 공유기(같은 Wi-Fi)의 Quest에만 읽기 전용으로 보여 줍니다. 인터넷으로 보내지 않습니다.

[사용 방법]
1. 이 폴더를 원하는 곳(예: 문서)에 그대로 둡니다. exe 파일만 따로 옮기지 마세요.
2. "SHARP PC Server.exe"를 두 번 누릅니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   - Windows 방화벽 창이 뜨면 "개인 네트워크"에 체크하고 [액세스 허용]을 누릅니다.
3. 처음 실행하면 "문서\SHARP VR" 폴더가 만들어지고 열립니다. 볼 파일을 여기에 넣으세요.
4. Quest의 SHARP 뷰어에서 [PC] 탭을 누릅니다. 처음 한 번은 30초쯤 걸릴 수 있습니다.
5. 끝낼 때는 검은 창을 닫거나 Ctrl+C를 누릅니다. 창이 열려 있는 동안만 연결됩니다.

[다른 폴더를 쓰려면]
- Choose-Shared-Folder.cmd 를 실행해 폴더를 고릅니다. 고른 폴더는 기억됩니다.
- 또는 폴더를 "SHARP PC Server.exe" 아이콘 위로 끌어다 놓습니다.
- 기억한 폴더를 모두 지우고 처음 상태로 돌리려면 Reset-Shared-Folders.cmd 를 실행합니다.

[연결이 안 되면]
- Quest와 PC가 같은 공유기에 연결되어 있는지 확인하세요.
- Windows 설정 > 네트워크 및 인터넷 > 현재 연결의 "네트워크 프로필 유형"이 "개인"인지 확인하세요.
- 방화벽에서 막았다면: Windows 보안 > 방화벽 및 네트워크 보호 > 방화벽에서 앱 허용
  > "SHARP PC Server"의 "개인"에 체크합니다.
- 검은 창에 나온 "PC 주소"(예: http://192.168.0.23:8787)를 앱의 [PC] 탭 > "고급: 주소 직접 입력"에 적습니다.

[알아 두세요]
- 공유 폴더는 같은 네트워크의 기기에 읽기 전용으로 보입니다. 집처럼 믿을 수 있는 네트워크에서만 실행하세요.
- 설정은 %LOCALAPPDATA%\SHARP PC Server 에 저장됩니다. 지우려면 이 폴더를 지우면 됩니다.
