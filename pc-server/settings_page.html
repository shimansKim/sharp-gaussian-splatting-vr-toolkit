조이스틱 버튼 설정

Quest 컨트롤러의 버튼을 짧게 또는 길게 눌렀을 때 할 동작을 고르세요.

초록색 버튼을 누르면 해당 설정으로 이동합니다. 점선 버튼(Meta)은 바꿀 수 없습니다.

저장한 설정은 Quest 앱이 PC에 연결되거나 다시 켜질 때 적용됩니다.

도움말

Quest에서 PC가 안 보일 때

1. PC와 Quest가 같은 Wi-Fi에 있나요?

둘 다 같은 공유기에 연결되어 있어야 합니다. 카페·회사처럼 기기끼리 통신이 막힌 Wi-Fi에서는 연결되지 않을 수 있습니다.

2. Windows 방화벽 창에서 허용했나요?

앱을 처음 켤 때 방화벽 창이 뜨면 개인 네트워크에 체크하고 [액세스 허용]을 누르세요. 놓쳤다면 Windows 설정에서 “방화벽을 통해 앱 허용”을 찾아 SHARP PC 서버를 허용하세요.

3. 네트워크가 “개인”으로 되어 있나요?

Windows 설정 > 네트워크 및 인터넷 > 지금 연결된 Wi-Fi(또는 이더넷)의 네트워크 프로필을 “개인 네트워크”로 바꾸세요.

4. 그래도 안 보이면 주소를 직접 입력하세요

홈의 “이 PC의 주소”를 복사해 Quest 앱 [PC] 탭 > “고급: 주소 직접 입력”에 적으세요.

5. 폴더는 보이는데 파일이 안 나와요

공유 폴더에서 폴더별 파일 수를 확인하세요. “찾을 수 없음”으로 나오면 외장 드라이브가 연결되어 있는지 확인한 뒤 옵션의 [서버 다시 시작]을 누르세요.

알아 두세요

공유 폴더는 같은 네트워크에 있는 기기에 읽기 전용으로 보입니다. 집처럼 믿을 수 있는 네트워크에서만 쓰세요.
