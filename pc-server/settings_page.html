PC 주소

Quest 앱이 PC를 자동으로 못 찾으면 [PC] 탭의 “고급: 주소 직접 입력”에 아래 주소를 적으세요.

공유 폴더

여기 있는 폴더의 PLY·영상·사진이 같은 네트워크의 Quest에 읽기 전용으로 보입니다.

옵션

포트
Quest가 접속하는 포트입니다. 기본값 . 바꾸면 Quest 앱에서 주소를 다시 확인해야 할 수 있습니다.

컨트롤러 버튼 지정

Quest 컨트롤러의 어느 버튼에 어떤 동작을 줄지 PC 화면에서 정합니다.

연결이 안 될 때

  1. Windows 방화벽 창이 뜨면 개인 네트워크를 허용하세요.
  2. 설정 > 네트워크 및 인터넷 > 현재 연결의 네트워크 프로필이 “개인”인지 확인하세요.
  3. Quest와 PC가 같은 Wi-Fi(공유기)에 있어야 합니다.
  4. 그래도 못 찾으면 위 PC 주소를 Quest 앱 [PC] 탭 > “고급: 주소 직접 입력”에 적으세요.

공유 폴더는 같은 네트워크의 기기에 읽기 전용으로 보입니다. 집처럼 믿을 수 있는 네트워크에서만 쓰세요.

앱

이 창을 닫아도 앱은 트레이(화면 오른쪽 아래 아이콘)에서 계속 실행됩니다. 끝내면 Quest에서 PC에 연결할 수 없습니다.
