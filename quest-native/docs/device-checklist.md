# 실기기 확인 순서표(Quest 3)

헤드셋을 처음 연결했을 때 위에서부터 차례로 확인한다.
각 구성원이 "실기기에서 볼 것"으로 남긴 항목을 한 장에 모았다.
원문: `docs/video-player.md` 7절, `cpp/image/README.md`, `measure/splat/README.md`, `docs/decoder-diagnostics.md`, `docs/storage-access.md`, `docs/pc-source.md`, ui PR(#72·#77·#84·#87).

- **준비**
  - [install-guide.md](install-guide.md) 1~4단계로 앱을 설치한다(`build_and_install.bat`).
  - 시험 파일: PLY 1개, 영상 2~3개(2D, VR180 좌우, 360 위아래), 사진 2~3개를 헤드셋 `Download/SHARP`에 복사한다.
- **안 되면** 그 자리에서 `tools\collect_log.bat`을 더블클릭한다. 저장된 로그 파일과 함께 **항목 번호, 본 것, 기대한 것**을 알려 준다.
  - 화면이 이상하면 헤드셋 사진도 함께 보낸다(헤드셋 안 스크린샷: Meta 버튼 메뉴의 카메라 **[추정]**).
- 결과는 표의 "결과" 칸에 ✔ / ✘ / 메모로 적는다.

## A. 시작과 화면

| # | 할 일 | 보여야 할 것 | 결과 |
|---|---|---|---|
| A1 | 앱을 켠다 | 몰입 화면(어두운 배경)과 앞쪽 파일 패널. 멈춤·검은 화면 없음 | |
| A2 | `collect_log.bat`으로 로그를 한 번 저장한다 | `[gpu] device=… api=1.3…` 줄(Vulkan 1.3인지), `[core] projection swapchain`, `[ui] 3 panels attached`, `[video] started (surface swapchain yes)` | |
| A3 | 패널 글씨를 본다 | 글씨가 **뒤집히지 않고** 또렷하다. 패널 모서리가 둥글고 바깥이 투명하다(검은 사각형이 아님) | |
| A4 | 컨트롤러로 패널을 가리킨다 | 컨트롤러에서 패널까지 얇은 레이 선, 패널 위 흰 커서 점 | |
| A5 | 트리거로 버튼을 누르고, 목록에서 스틱을 위아래로 민다 | 눌림 표시, 목록 스크롤(오래 밀수록 빨라짐) | |
| A6 | B 짧게 → B 짧게 → B 길게(0.6초) | UI 꺼짐 → 켜짐 → UI가 지금 보는 곳으로 옮겨짐 | |
