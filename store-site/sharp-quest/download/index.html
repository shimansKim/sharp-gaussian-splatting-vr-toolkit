SHARP PC 서버 (Windows)

PC에 있는 PLY·영상·사진을 Quest의 SHARP 뷰어에서 보게 해 주는 프로그램입니다. Quest에 있는 파일만 볼 때는 필요 없습니다.

다운로드 Windows 10·11 64비트용 zip 파일입니다. Python을 따로 설치하지 않아도 됩니다.

  • 크기: 릴리스 페이지에 표시
  • SHA-256: 릴리스 페이지에 표시

설치와 실행

  1. 내려받은 zip 파일을 마우스 오른쪽 버튼으로 누르고 [압축 풀기]를 누릅니다. 압축을 푼 폴더를 문서 같은 곳에 그대로 둡니다.
  2. 폴더 안의 SHARP PC Server.exe를 두 번 누릅니다.
  3. 처음 실행하면 문서\SHARP VR 폴더가 만들어지고 열립니다. Quest에서 볼 파일을 여기에 넣으세요.
  4. Quest의 SHARP 뷰어에서 [PC] 탭을 누릅니다. 처음 한 번은 PC를 찾는 데 30초쯤 걸릴 수 있습니다.
  5. 검은 창이 열려 있는 동안만 연결됩니다. 끝낼 때는 창을 닫으세요.

"Windows의 PC 보호" 창이 뜰 때

이 프로그램은 아직 코드 서명이 없어 Windows가 처음 보는 프로그램으로 경고합니다.

  1. 파란 창에서 [추가 정보]를 누릅니다.
  2. 게시자가 "알 수 없는 게시자"로 나오면 [실행]을 누릅니다.

걱정되면 실행 전에 파일의 SHA-256 값이 위에 적힌 값과 같은지 확인하세요. PowerShell에서 Get-FileHash .\파일이름.zip을 실행하면 값이 나옵니다.

Windows 방화벽 창이 뜰 때

Quest가 PC에 접속하려면 허용이 필요합니다.

  1. "개인 네트워크"에 체크합니다. "공용 네트워크"는 체크하지 않아도 됩니다.
  2. [액세스 허용]을 누릅니다.

실수로 막았다면 Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 → [설정 변경]을 누르고, "SHARP PC Server"의 "개인"에 체크합니다.

다른 폴더를 보여 주려면

  • 압축을 푼 폴더의 Choose-Shared-Folder.cmd를 실행해 폴더를 고릅니다. 고른 폴더는 다음 실행에도 기억됩니다.
  • 또는 폴더를 SHARP PC Server.exe 아이콘 위로 끌어다 놓습니다.
  • 처음 상태로 돌리려면 Reset-Shared-Folders.cmd를 실행합니다.

알아 두세요

  • 공유 폴더는 같은 공유기(Wi-Fi)에 연결된 기기에 읽기 전용으로 보입니다. 집처럼 믿을 수 있는 네트워크에서만 실행하세요.
  • 파일은 인터넷으로 나가지 않고 Quest와 PC 사이에서만 오갑니다.
  • 설정은 %LOCALAPPDATA%\SHARP PC Server에 저장됩니다. 지우려면 이 폴더와 압축을 푼 폴더를 지우면 됩니다.
  • 포함된 오픈소스 고지는 압축을 푼 폴더의 licenses에 있습니다.
  • 연결이 안 되면 지원 페이지를 보세요.

SHARP PC Server (Windows)

This program lets SHARP Viewer on Quest show PLY files, videos, and photos stored on your PC. You do not need it to view files stored on the Quest itself.

Download A zip for Windows 10/11 64-bit. No separate Python installation is needed.

  • Size: shown on the release page
  • SHA-256: shown on the release page

Install and run

  1. Right-click the downloaded zip and choose Extract All. Keep the extracted folder somewhere such as Documents.
  2. Double-click SHARP PC Server.exe in that folder.
  3. On first run it creates and opens Documents\SHARP VR. Put the files you want to view there.
  4. In SHARP Viewer on Quest, open the PC tab. The first search may take about 30 seconds.
  5. The connection works only while the black window is open. Close the window to stop.

If "Windows protected your PC" appears

The program is not code-signed yet, so Windows warns about an unrecognized app.

  1. Click More info.
  2. When the publisher shows as "Unknown publisher", click Run anyway.

If you want to be sure, check that the file's SHA-256 matches the value above. In PowerShell, run Get-FileHash .\file-name.zip.

If a Windows Firewall prompt appears

  1. Check "Private networks". You do not need to check "Public networks".
  2. Click Allow access.

If you blocked it by mistake, go to Windows Security → Firewall & network protection → Allow an app through firewall → Change settings, and check "Private" for "SHARP PC Server".

Sharing other folders

  • Run Choose-Shared-Folder.cmd in the extracted folder and pick a folder. It is remembered for next time.
  • Or drag a folder onto the SHARP PC Server.exe icon.
  • Run Reset-Shared-Folders.cmd to go back to the default.

Good to know

  • Shared folders are visible read-only to devices on the same router (Wi-Fi). Run it only on a network you trust, such as at home.
  • Files never go to the internet; they travel only between your Quest and your PC.
  • Settings are stored in %LOCALAPPDATA%\SHARP PC Server. Delete that folder and the extracted folder to remove everything.
  • Open-source notices are in the licenses folder.
  • If it does not connect, see the Support page.
