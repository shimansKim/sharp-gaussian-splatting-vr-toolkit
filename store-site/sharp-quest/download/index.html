Splatia PC Server (Windows)

PC에 있는 PLY·영상·사진을 Quest의 SHARP 뷰어에서 보게 해 주는 프로그램입니다. Quest에 있는 파일만 볼 때는 필요 없습니다.

다운로드 v1.1.1 · Splatia-PC-Server-1.1.1-Setup.exe Windows 10·11 64비트용 설치 파일(Setup.exe)입니다. Python을 따로 설치하지 않아도 됩니다. 관리자 권한 없이 내 계정에만 설치됩니다.

  • 크기: 6.6 MB (6,970,272 bytes)
  • SHA-256: f66c0199d069538d3cb32543052972265ce47de3c913f15102e764a05486de80
  • 설치 없이 쓰려면 zip 파일을 받아 압축을 풀고 Splatia PC Server.exe를 실행하세요.

설치와 실행

  1. 내려받은 Splatia-PC-Server-…-Setup.exe를 두 번 누릅니다.
  2. 안내에 따라 [다음]을 누릅니다. 바탕화면 바로가기와 "Windows를 시작할 때 자동으로 실행"은 원하면 체크하세요.
  3. 설치가 끝나면 [Splatia PC Server 실행]을 눌러 시작합니다. 시작 메뉴의 "Splatia PC Server"로도 실행할 수 있습니다.
  4. 작업 표시줄 오른쪽 아래(트레이)에 아이콘이 나타납니다. 아이콘을 두 번 누르면 관리 창이 열립니다. 여기서 공유 폴더와 옵션을 관리합니다.
  5. 처음 실행하면 문서\SHARP VR 폴더가 공유됩니다. Quest에서 볼 파일을 여기에 넣으세요.
  6. Quest의 SHARP 뷰어 목록에서 [PC] 항목을 엽니다. 처음 한 번은 PC를 찾는 데 30초쯤 걸릴 수 있습니다.
  7. 트레이 아이콘을 오른쪽 버튼으로 눌러 [종료]를 선택할 때까지 연결이 유지됩니다.

"Windows의 PC 보호" 창이 뜰 때

이 프로그램은 아직 코드 서명이 없어 Windows가 처음 보는 프로그램으로 경고합니다.

  1. 파란 창에서 [추가 정보]를 누릅니다.
  2. 게시자가 "알 수 없는 게시자"로 나오면 [실행]을 누릅니다.

걱정되면 실행 전에 파일의 SHA-256 값이 위에 적힌 값과 같은지 확인하세요. PowerShell에서 Get-FileHash .\파일이름.exe을 실행하면 값이 나옵니다.

Windows 방화벽 창이 뜰 때

Quest가 PC에 접속하려면 허용이 필요합니다.

  1. "개인 네트워크"에 체크합니다. "공용 네트워크"는 체크하지 않아도 됩니다.
  2. [액세스 허용]을 누릅니다.

실수로 막았다면 Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 → [설정 변경]을 누르고, "Splatia PC Server"의 "개인"에 체크합니다.

다른 폴더를 보여 주려면

  • 트레이 아이콘을 두 번 눌러 관리 창을 열고 공유 폴더를 추가하거나 뺍니다. 설정은 다음 실행에도 기억됩니다.

알아 두세요

  • 공유 폴더는 같은 공유기(Wi-Fi)에 연결된 기기에 읽기 전용으로 보입니다. 집처럼 믿을 수 있는 네트워크에서만 실행하세요.
  • 파일은 인터넷으로 나가지 않고 Quest와 PC 사이에서만 오갑니다.
  • 지우려면 Windows 설정 → 앱 → 설치된 앱에서 "Splatia PC Server"를 제거하세요. 제거할 때 저장된 설정(%LOCALAPPDATA%\SHARP PC Server)을 지울지 묻습니다.
  • 설정은 %LOCALAPPDATA%\SHARP PC Server에 저장됩니다.
  • 포함된 오픈소스 고지는 설치 폴더의 licenses에 있습니다.
  • 연결이 안 되면 지원 페이지를 보세요.

Splatia PC Server (Windows)

This program lets SHARP Viewer on Quest show PLY files, videos, and photos stored on your PC. You do not need it to view files stored on the Quest itself.

Download v1.1.1 · Splatia-PC-Server-1.1.1-Setup.exe A Windows 10/11 64-bit installer (Setup.exe). No separate Python installation is needed. It installs for your account only and needs no administrator rights.

  • Size: 6.6 MB (6,970,272 bytes)
  • To use it without installing, download the zip file, extract it, and run Splatia PC Server.exe.
  • SHA-256: f66c0199d069538d3cb32543052972265ce47de3c913f15102e764a05486de80

Install and run

  1. Double-click the downloaded Splatia-PC-Server-…-Setup.exe.
  2. Follow the prompts. Check the desktop shortcut and "Start automatically when Windows starts" if you want them.
  3. When setup finishes, choose Launch Splatia PC Server. You can also start it from the Start menu.
  4. An icon appears in the tray at the lower right of the taskbar. Double-click it to open the management window, where you manage shared folders and options.
  5. On first run it shares the Documents\SHARP VR folder. Put the files you want to view there.
  6. In SHARP Viewer on Quest, open the PC entry in the list. The first search may take about 30 seconds.
  7. The connection stays up until you right-click the tray icon and choose Quit.

If "Windows protected your PC" appears

The program is not code-signed yet, so Windows warns about an unrecognized app.

  1. Click More info.
  2. When the publisher shows as "Unknown publisher", click Run anyway.

If you want to be sure, check that the file's SHA-256 matches the value above. In PowerShell, run Get-FileHash .\file-name.exe.

If a Windows Firewall prompt appears

  1. Check "Private networks". You do not need to check "Public networks".
  2. Click Allow access.

If you blocked it by mistake, go to Windows Security → Firewall & network protection → Allow an app through firewall → Change settings, and check "Private" for "Splatia PC Server".

Sharing other folders

  • Double-click the tray icon to open the management window, then add or remove shared folders. Your choices are remembered for next time.

Good to know

  • Shared folders are visible read-only to devices on the same router (Wi-Fi). Run it only on a network you trust, such as at home.
  • Files never go to the internet; they travel only between your Quest and your PC.
  • Settings are stored in %LOCALAPPDATA%\SHARP PC Server. To remove the app, uninstall "Splatia PC Server" in Windows Settings → Apps → Installed apps. Uninstall asks whether to delete the saved settings too.
  • Open-source notices are in the licenses folder of the install folder.
  • If it does not connect, see the Support page.
