허용된 BAT 목록만 실행합니다.
1. 환경 확인CUDA, PyTorch, SHARP 상태를 먼저 봅니다.
2. 이미지 변환이미지 또는 폴더를 PLY로 만듭니다.
3. PLY 렌더링일반 MP4 또는 SBS 양안 영상으로 확인합니다.
4. 영상 파이프라인긴 영상은 5프레임 테스트 후 전체 실행합니다.
5. YouTube 변환Quest에서 잘 보였던 3D/VR 메타데이터를 적용합니다.
6. Quest 확인WebXR 뷰어에서 safe1~safe10 품질을 비교합니다.
